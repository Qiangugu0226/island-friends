# 背景故事与地方特色：决策文档

> 状态：**待你拍板（地点取向 + 故事框架）**
> 这是 P1.5 / P2 之前必须定的事——它决定了建筑、道具、植被、命名、文案的整套基调。

---

## 0. 先说清楚现状（一个必须解决的不一致）

| 现有元素 | 目前的取向 |
| --- | --- |
| 红白条纹灯塔 | 欧洲/地中海航标造型 |
| 白墙 + 人字坡屋顶 + 烟囱 | 西欧乡村民居 |
| 木栅栏、木栈桥、木船 | 偏西式渔村 |
| 圆润多色树冠（橘/红/黄/绿） | 无地域性，童话感 |
| 动物名字：大黄 / 煤球 / 啾啾 / 慢慢 | **中式昵称** |
| 「朋友簿」「好感度」「秘密网络」 | 偏中式/日式的日常叙事 |

**结论**：现在是「西式场景 + 中式叙事」。要么统一到中式，要么统一到架空童话。这一步不定，后面每加一个道具都要纠结一次。

## 1. 地点取向：四个选项

### 方案 A · 中国东南沿海渔村小岛 ★ 推荐（配合故事框架用）
取材闽南 / 浙东 / 粤东 / 海南一带的海岛渔村。

- **建筑**：石厝（花岗岩砌墙）或白墙灰瓦；屋顶改**燕尾脊 / 马鞍墙**；去掉西式烟囱，改**小烟囱或灶间出烟口**
- **地标**：红白条纹灯塔 → 改**中式航标塔**（白塔身 + 红顶，或石砌灯桩），或保留一座"老灯塔"（可解释为早年外国船留下的，反而成了故事点）
- **信仰/生活**：土地庙 / 妈祖小庙（一间小屋 + 香炉），晒渔网架、晒鱼干、竹编鱼篓、水缸、石磨、石板路、石阶码头、红灯笼、榕树（替代部分圆冠树）、芭蕉/椰树、梯田式菜畦
- **故事**：台风、出海、渔汛、外婆的灶台、夏天、蝉鸣——**天然适合「无失败、无计时、慢慢来」的治愈叙事**
- **返工量**：中（房子/灯塔/码头/植被/道具，约 1 个工作版次，全部程序化）

### 方案 B · 地中海 / 西欧小渔岛
贴合现在的画面与 Piggy Island 参考图。白墙红瓦、红白灯塔、风车、松树与橄榄树、木栈桥。

- 优点：**零返工**，现在就能继续做玩法
- 缺点：文化具体性弱，写"地方特色"的故事会很空；和中国玩家没有天然情感连接

### 方案 C · 架空童话岛（不指向任何国家）
现在这套资产直接沿用，世界观自造（比如"世界尽头的最后一座岛"）。

- 优点：最自由，不必考据
- 缺点：没有"地方特色"——而这正是你想要的

### 方案 D · 中式骨架 + 童话配色（实为 A 的执行方式）
把 A 的中国海岛元素，用 B 已有的**低多边形可爱语言 + 暖奶油/青绿配色**重做一遍。

> 说明：D 不是另一个地点，而是"A 的渲染方式"。**推荐直接选 A，用 D 的方式画**——既保留地方特色，又不丢现在的画风。

## 2. 故事框架：三个选项

### 框架 1 · 暑假回乡（最贴合"无失败无压力"）
小孩放暑假被送到海岛上的外婆家。大人们出海／出岛，岛上安静得只剩风声和动物。玩家用一整个夏天，慢慢和岛上的动物成为朋友。

- 基调：怀旧、温吞、日常；**与「漫步式无计时」完美契合**
- 台词方向：外婆的碎碎念、动物的小脾气、村里的旧事
- 动物会说话的解释：不需要解释（童话默认），或"只有小孩听得懂"

### 框架 2 · 台风之后
一场台风把岛上动物吓散、窝也毁了。玩家要重新取得它们的信任，帮它们把家一点点修回来。

- 基调：有点目标感与轻冲突，但仍然零失败
- 好处：**天然解释"为什么动物一开始躲着你"**，也解释"为什么会解锁新区域"
- 风险：容易写成"任务清单"，破坏治愈感（要克制）

### 框架 3 · 守岛人传说（奇幻）
岛上的动物其实是"守岛人"——土地庙与灯塔的看护者。玩家是唯一能听懂它们的孩子，慢慢揭开这座岛为什么被世界遗忘的秘密。

- 基调：温柔的奇幻，有悬念
- 好处：**给"动物会说话""为什么能解锁能力（猫上高处/鸟飞高/龟下水）"一个自洽的设定**
- 风险：世界观一旦铺开，后期内容压力大

**组合建议**：**框架 1 的外壳 + 框架 3 的里子** —— 表面是暑假回乡的日常，随着好感度提升，动物陆续说出"守岛人"的旧事（这也正是「秘密网络」闭环需要的东西）。

## 3. 定了之后，我们按这个顺序对细节（一步步来）

1. **岛名 / 村名**（例：金屿、猫屿、大榕屿、半月屿）
2. **玩家是谁**：性别、年龄、从哪来（现在模型是中性短发小孩，衣服橙红）
3. **岛上还有别人吗**：外婆／爷爷／老渔民作为 NPC，还是"大人都出海了"
4. **年代**：现代（有手机/电灯）还是怀旧（上世纪八九十年代，无电子设备）
5. **信仰与禁忌**：庙要几座、拜什么；有没有"不能碰的东西"
6. **动物与人的关系**：动物为什么会说话、为什么认生（框架 3 的设定）
7. **文字**：简体中文 UI、文案口径（动物名字是否要更中式：大黄→来福？保持现行也完全可以）
8. **音乐音效方向**：蝉鸣、海浪、渔号子、庙里风铃、蟋蟀
