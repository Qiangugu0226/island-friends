## 1. 这一版改了什么

把 P1 的「西欧乡村」资产体系换成 **中国东南沿海渔村**，渲染语言与配色仍是 P1 那套童话化低多边形（暖奶油天空 + 青绿海水 + 黄绿草地），**地形 / 海 / 浪花 / 玩家 / 相机 / 昼夜全部复用，没动系统层**。

| 类别 | P1（旧） | P1.5（新） |
| --- | --- | --- |
| 民居 | 白墙 + 人字坡屋顶 + 西式烟囱 | **石厝 / 白墙 / 红砖厝** 三种形制 + **燕尾脊**（正脊两端上扬翘角）+ 灶间出烟口 + 门联 + 石阶 + 木格窗 |
| 院墙 | 木栅栏 | **石砌矮墙**（带压顶石，朝村子中心自动留门洞） |
| 地标 | 红白条纹灯塔 | **航标塔**（石基座 + 白塔身 + 红腰带 + 红顶 + 灯室），夜里亮灯 |
| 信仰 | 无 | **土地庙**（燕尾脊小屋 + 供桌 + 香炉 + 三炷香 + 一对红灯笼） |
| 码头 | 木栈桥 + 西式小船 | **石阶码头**（石阶下海 + 石砌墩 + 系缆桩）+ **木渔船**（竹篷 + 桨 + 渔网堆 + 鱼篓） |
| 渔业道具 | 无 | **晒渔网架**（格子网）+ **晒鱼干架**（挂鱼）+ 水缸 + 竹篓 |
| 菜地 | 平铺菜畦 | **梯田菜畦**（三级土坎 + 石砌挡土墙 + 菜行） |
| 道路 | 土路 | **石板路**（沿道路铺石板，约 300+ 块，双色错落） |
| 植被 | 多色圆冠树 + 灌木 + 草丛 | 保留 + 新增 **榕树**（粗干宽冠 + 垂气根）、**芭蕉**（叶冠）、**竹丛** |
| 小景 | 路灯、长椅、晾衣绳、信箱 | **灯笼路灯**（红灯笼，夜里亮）+ **石凳** + 晾衣绳（靛蓝布）+ 中式水井（辘轳 + 木桶）+ 石磨 + 稻草堆 + 木桶 + 南瓜 |
| 色板 | 红/黄/青/绿屋顶 | **灰瓦 + 石墙**为主，朱红/青灰点缀；灯笼红、竹青、靛蓝 |

## 2. 场景现状（岛上有什么）

- **村中心**：4 栋石厝小院（石 / 白 / 红砖 / 石），各有石砌院墙、门联、水缸、竹篓、木桶
- **村口**：土地庙 + 两棵庙前老榕树 + 石凳 + 灯笼路灯
- **岛北岬角**：航标塔（可作后期「老灯塔停灯」的剧情点）
- **西南海岸**：石阶码头 + 木渔船 + 晒渔网架 + 晒鱼干架（**玩家出生点就在码头附近，符合"坐船来岛上过暑假"的设定**）
- **东南**：梯田菜畦 + 稻草堆 + 南瓜地
- **全岛**：石板路网络、2 个池塘（荷叶）、榕树 / 芭蕉 / 竹丛散布

## 4. 新增的调试/验收工具

| --- | --- |
| `?cam=x,y,z&look=x,y,z` | **自由相机**：直接把镜头放到指定位置，用于给某件资产拍特写（我截图和你排查都用它） |

## 6. 已知问题

| 项 | 说明 |
| --- | --- |
| 燕尾脊仍是"方盒近似" | 目前用两段斜置方盒叠出上扬曲线，近看是折线，不是顺滑曲线；P5 可换成自定义曲线几何 |
| 瓦垄（瓦片纹理）未做 | 屋顶是大色块，没有瓦纹；要的话 P5 加 |
| 渔网是格子几何，不是真网 | 低模表达，够用 |

| 画廊视角偏远 | 资产总览是"总览"，逐件看建议用 `?cam=` 拍特写 |
