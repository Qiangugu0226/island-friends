## 1. 一句话设定

一个小孩被送到**东南沿海的渔村小岛**过暑假；大人们出海、上工，岛上安静得只剩风、蝉鸣和动物。
用一个夏天慢慢和岛上的动物交朋友——直到它们开始讲起**守岛人**的旧事。

## 2. 地点

| 项 | 设定（暂定，可改） |
| --- | --- |
| 地理 | 中国东南沿海的离岛渔村（参照闽南 / 浙东 / 粤东一带） |
| 岛名（暂定） | **半月屿**（备选：金屿、猫屿、大榕屿） |
| 村子 | 岛中央的**石厝村**，十几户人家，环岛有石阶码头、菜畦、晒场、土地庙 |
| 气候 | 夏日、海风、午后蝉鸣；偶有雷雨与台风季 |
| 地标 | **老航标塔**（白塔身红顶，立在岛北岬角）、**土地庙**与庙前老榕树、晒渔网的木架、石阶码头 |
| 时间基调 | 怀旧向的现代（有电灯、有广播喇叭，但没有手机与网络的存在感） |

## 3. 玩家与人物

| 项 | 设定（暂定） |
| --- | --- |
| 玩家 | 城里来的小孩（性别不做限定，模型保持中性；衣服可后期换） |
| 为什么在岛上 | 放暑假被送到岛上长辈家 |
| 岛上的人 | 大人白天出海/上工，村口偶有老人；**人是背景，动物才是主角** |
| 动物 | **大黄**（狗，守着一根旧骨头）、**煤球**（猫，白天睡、嘴硬心软）、**啾啾**（鸟，全村情报贩子）、**慢慢**（龟，背壳上刻着一生的故事） |
| 说话规则 | 岛上动物会说话，只有小孩听得懂（守岛人设定的表层体现） |

## 4. 故事框架（外壳 1 + 里子 3）

- **外壳（暑假回乡）**：没有反派、没有倒计时、没有失败。玩家用一整个夏天和动物做朋友。
- **里子（守岛人传说）**：这座岛的动物被老辈人称作"守岛人"——它们替出海的人看着岛、看着灯塔与土地庙。
  随着好感度提升，动物陆续把旧事讲出来：谁在等谁回来、哪一年台风、航标塔为什么停过灯。
- **两条线的关系**：外壳提供**节奏与情绪**（慢、日常、治愈），里子提供**动力与悬念**（好感度越高，秘密越多）。
  这正是「秘密网络」闭环需要的东西：**帮一只动物 → 得到另一只动物的线索**。

## 5. 与玩法的绑定（设计层，不做内容）

| 设定 | 对应玩法 |
| --- | --- |
| 动物一开始躲着城里来的小孩 | 「陌生」等级：靠近就跑 |
| 守岛人的旧事要"对象"才能讲 | 好感「熟悉 60+」解锁**小秘密**（其他动物的线索） |
| 猫上高处、鸟飞高、龟下水 | 挚友后的**动物小队能力**（设定上它们是守岛人，各守一处） |
| 航标塔停过灯 / 台风那一年 | 后期剧情与天气系统的钩子 |
