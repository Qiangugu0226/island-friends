## 1. 我从参考图里读到的「风格基因」

| 维度 | 观察 | 怎么用在小岛朋友 |
| --- | --- | --- |
| 色彩 | 暖奶油天空 + 高饱和青绿海水 + 黄绿草地 + 暖沙色，**整体偏暖、明亮、饱和度中高** | 直接沿用为主色板，动物用更跳的强调色 |
| 造型 | 场景是**低多边形硬边切面**；树冠是多面体块面 | 场景用 `flatShading` 几何，代码生成 |
| 对比 | 角色圆润平滑 + 简单五官，与硬边场景**形成反差** | 动物做成圆润、平滑法线、卡通比例 |
| 光影 | 单一主光（太阳）+ **柔和长投影**，无强烈明暗对比 | 一盏平行光 + 半球光补色，软阴影 |
| 边缘 | 干净色块，**无黑色描边**；水面有白色浪花描边和细波纹线 | 海水用白边 shader；不描边，靠色彩分层 |
| 海 | 浅青 → 中青分层，白色泡沫环绕岛屿 | 岛屿周围一圈浪花环 + 水下浅色带 |
| 地标 | 红白条纹灯塔 + 红顶 + 木栅栏平台 | 岛的视觉锚点，可作后期「鸟起飞」坐标点 |
| 氛围 | 夏日、宁静、有生活痕迹（栅栏、菜地、小船、栈桥） | 加生活小道具，别让岛显得空 |

## 2. 三个可选方案（选一个，或混搭）

### 方案 A：Piggy Island 手绘低多边形 ★ 推荐
- **做法**：程序化低多边形几何 + 顶点色 + 柔和平行光 + 渐变天空球 + 雾；后期再加手绘质感贴图
- **优点**：最接近参考图；v1 **不需要任何美术资源**就能出效果；改数字即可调整
- **代价**：初期看起来比参考图「干净/塑料」一点，手绘笔触要后期打磨
- **完成度预期**：P1 就能看到「像 Piggy Island 的小岛」轮廓

### 方案 B：纯低多边形 flat-shading（更冷、更简约）
- **做法**：去掉暖色渐变和手绘感，接近 Monument Valley / 纯色低多边形
- **优点**：最快、最省钱
- **代价**：失去参考图的「暖奶油 + 夏日」温度，治愈感会打折

### 方案 C：2D 手绘 / Sprite 插画风
- **做法**：角色与场景用 2D 手绘素材，接近参考图的插画质感
- **优点**：质感最好，最像参考图下半张
- **代价**：需要大量美术资源（每只动物多方向动画），**与「先跑通闭环」冲突**，且你必须自己出图或找美术

> 我的建议：**A 起步，保留升级到 C 的接口**。也就是先用代码做出 A 的氛围，等你看到实际效果再决定要不要往手绘质感推。

## 4. 视觉规范（v1 执行标准）

- **相机**：斜俯视 3rd person（俯角约 35°–45°），视野 50°–60°，柔和跟随 + 缓动
- **投影**：开启软阴影；远景用假投影贴片降性能开销
- **雾**：暖色雾，远处淡出到天空色，营造「小岛」的封闭感
- **比例**：卡通比例——房子约玩家 2.5 倍高，树约 3–4 倍，池塘占地图 1/8
- **禁用**：低对比灰调、写实材质、暗黑/夜晚过暗（夜晚用蓝紫 + 灯火暖光，不压黑）
- **UI**：圆角、暖白色卡片、手绘感边框，与 galgame 观察卡/对话框统一
