## P1 · 能走路的小岛（Walking Skeleton）

**目标**：一分钟内你能在浏览器里走动，看到「像 Piggy Island 的小岛」。

**我交付**
- Vite + Three.js 项目骨架（`npm run dev` 即可跑）
- 岛屿地形（草地 + 沙滩 + 环岛海岸线 + 白浪花描边）+ 海水
- 奶油渐变天空 + 暖雾 + 一盏太阳光软阴影
- 程序化散布：树 / 草丛 / 石头 / 野花 / 树桩（数量在 `world.json` 调）
- 4 栋农家小院（3 种屋顶色）+ 2 个池塘 + 土路 + 灯塔地标
- 玩家角色（低模小人）+ 第三人称跟随相机 + 走路动画
- 昼夜时间系统（可加速，用于验收不同时段画面）

**资产清单（你会收到）**：`world.json` 全部可调参数 + 一组调试截图（俯视全景 / 地面视角 / 黄昏）

**你的验收点**：岛的氛围对不对、颜色对不对、密度手感、相机跟手不跟手、帧率

**明确不做**：动物、系统、UI（留到 P2）

**✅ 实际交付（2026-09-13）**：完整说明与截图见 `04-p1-delivery.md`。实际比计划多做：程序化资产总览视角、道路网络、菜地、栈桥小船、环岛浪花 shader、建筑/地形相机避让、URL 调试参数、`?walk=1` 冒烟测试。开发服务器：`npm run dev`（当前 http://127.0.0.1:5199/）。

## P2 · 一只动物 + 信任闭环 MVP ★ 最关键

**目标**：只用**一只动物（大黄）**跑通「发现 → 潜行 → 观察 → 投喂 → 好感度」的手感核心。手感不对，游戏就不对。

**我交付**
- 动物状态机：躲藏 / 警觉 / 逃跑 / 好奇 / 信任 / 跟随（含头顶 `!` `?` 与表情气泡）
- 三层线索：远（草动/脚印/羽毛）、中（立体声叫声/咀嚼声，能听声辨位）、近（尾巴尖/眼睛反光）
- 蹲伏潜行（C 键）：正常走近=吓跑，蹲行=警觉，8 秒后放松；吓跑**无惩罚**
- 观察：3.5m 内准星变金黄 + E 键 → galgame 式观察卡（名字/性格/状态）
- 投喂：捡食物 → 喂对 → 好感 +20 + 头顶爱心；喂错只是「不感兴趣」
- 好感度 HUD（左上角，首次观察后出现）

**你的验收点**：吓跑的暴躁度、警觉的宽容度、蹲行速度、爱心反馈的爽感 —— 这些都是数值，我会给你一页 `animals.json` 让你直接改

**明确不做**：朋友簿、对话树、其他三只动物

## P3 · 闭环上墙

**目标**：一个 20 分钟的游玩循环完整可玩。

**我交付**
- 好感度四级解锁（陌生 / 认识 / 熟悉 / 挚友）与阈值可调
- 选项式对话系统 + 大黄的基础对话树（先由 mimo 批量生成、你筛选后入库）
- 朋友簿（手绘风日记界面，记录故事/性格/回忆）
- 秘密线索：大黄告诉你「乌龟爱听歌」→ 引出下一只动物的钩子
- 存档（localStorage）+ 读档 + 新档
- 完整的 HUD / 菜单流程

**你的验收点**：走完一遍「第一次遇到大黄 → 成为朋友」的完整流程，判断节奏与文案

## P4 · 四只动物 + 系统扩展

**我交付**：煤球、啾啾、慢慢（各自的躲藏点、食物、作息、秘密、对话）；动物小队跟随 + 四种能力 + 组合技；昼夜作息差异；天气系统（雨天躲屋檐、雷雨天狗的剧情）；食物道具与拾取点；小地图/标记

**你的验收点**：四只动物是否各有性格差异；小队能力是否好用；时间/天气是否真的改变体验
