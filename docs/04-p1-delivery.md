## 2. 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动（相对镜头方向） |
| `Shift` | 跑 |
| 鼠标 | 转视角（**先点一下画面**锁定指针；`Esc` 释放） |
| 滚轮 | 拉近拉远（5–30m） |
| `V` | 切换视角：跟随 / 全岛俯瞰 / 地面 / **资产总览** |
| `T` | 暂停/恢复时间 |
| `[` `]` | 时间速度档位（0 / 1x / 4x / 12x） |
| `R` | 回到出生点 |
| `H` | 隐藏/显示 HUD |

**资产总览视角（按 V 切到第 4 个）**：28 件资产排成 4 行、每件带标签，是给你逐件验收用的。

## 3. 这一版做了什么

| 模块 | 内容 |
| --- | --- |
| 地形 | 约 **125m 直径**的可行走小岛，海岸线带角度噪声（不是圆饼）；草地 / 沙滩 / 崖壁按高度与坡度逐面上色 |
| 海水 | 自定义 shader 海面（近岸浅青 → 远海深青、缓慢波光、阳光碎闪）+ **沿岸线生成的环岛浪花**（两层，跟着时间呼吸） |
| 天空与光照 | 奶油渐变天空穹顶 + 太阳光晕；一盏太阳平行光（软阴影）+ 半球补光 + 暖色雾 |
| 昼夜 | 8 个关键帧插值（夜/黎明/清晨/白天/傍晚/黄昏/夜晚），太阳东升西落，路灯与灯塔夜里自动亮起 |
| 散布 | 树 265（橘/红/黄/绿多色树冠）、灌木 340、石头 46、野花 260、树桩 48、草丛 900 —— 全部 `InstancedMesh`，自动避让道路/院子/池塘 |
| 建筑 | 4 栋不同屋顶色（红/黄/青/绿）的农家小院 + 院子栅栏（自动留门）+ 柴堆；红白条纹灯塔（地标，带夜景灯）；木栈桥 + 小船；菜地 |
| 小景 | 水井、石磨、干草堆、木桶、南瓜、长椅、路灯（夜景）、晾衣绳、信箱、池塘荷叶 |
| 池塘 | 2 个：挖碗地形 + 水面 + 荷叶 + 岸边石头 |
| 道路 | 斜坡土路网络（沿折线压平地形，5 条），玩家走在路上更平 |
| 玩家 | 低多边形小孩（躯干/头发/背包/四肢）+ 走路跑步动画 + 地形贴合 + 建筑碰撞 + 不下水 |
| 相机 | 第三人称斜俯视跟随（俯角 40°）+ 建筑/地形避让，另有 3 个固定观察视角 |
| 资产总览 | 独立的展示平台（离岛 620m），28 件资产带标签 |

**参考图对照**：暖奶油天空 ✅ 青绿海水 + 白浪花描边 ✅ 暖沙沙滩 ✅ 黄绿草地 ✅ 多色圆润树冠 ✅ 红白灯塔地标 ✅ 木栈桥 + 小船 ✅ 农家小院群 ✅ 低多边形硬边 + 柔和长投影 ✅

## 6. 我最想听你意见的 5 件事

1. **草地/沙滩的颜色**：现在偏「明快黄绿」，要不要更黄、更暖，或更饱和？
2. **树的密度与大小**：现在 265 棵、2.3–5.6m；参考图更密更圆，要加密吗？
3. **房子比例**：小院 9m 宽、屋脊约 6m 高，在 125m 的岛上显得偏小还是合适？
4. **海与浪花**：浪花带现在贴着岸线、比较克制；参考图更夸张一些（大圈白边），要不要加强？
5. **资产本身**：按 `V` 到「资产总览」，哪一件你觉得不对/不够可爱，直接点名，我重做。

## 9. URL 调试参数（我截图/你排查都能用）

```
?view=follow|top|ground|gallery   指定视角
?hour=18.6                        指定时间
?x=-10&z=6                        指定出生点
?hud=0                            隐藏 HUD
?walk=1                           自动向前走 3 秒并打印位移（冒烟测试）
?probe=1                          打印地形高度/颜色探针到控制台
?debug=flat|wire                  地形用纯色/线框渲染（排查用）
?hide=ocean,scatter,structures,ponds,terrain   临时隐藏某一层
```
