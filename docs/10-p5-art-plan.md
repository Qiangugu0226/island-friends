# P5 美术打磨计划（方向 B：手绘质感低多边形）

> 依据：你确认「美术方向 B 可以」，并同意「按我的建议来」——即 **P5 以 B 为目标，同时捡 C（黄昏电影感）里便宜的氛围元素**。
> 参考图：`concepts/art-B-handpainted.png`（目标）、`concepts/art-C-dusk-cinematic.png`（上限参考）

## 2. 建议的 P5 执行顺序

1. **A1 + A2 + A3**（贴图 + 瓦垄 + 墙缝）→ 一版就能看到质变
2. **B1 + B2**（色彩分级 + 接触阴影）→ 画面立刻"高级"
3. **C1 + C2 + C3**（夜灯 + 萤火 + 灯塔光束）→ 夜晚成为亮点
4. **D1 + D2**（动作曲线 + 风摆）→ 画面"活"起来
5. A4/A5、B3/B4、C4/C5/C6、E1–E3 → 收尾

## 3. 明确不做的（性价比低）

| 不做 | 原因 |
| --- | --- |
| 体积光 / 浅景深 | Three.js 里成本高、移动端掉帧，收益不如色彩分级 |
| PBR 物理材质 | 和手绘卡通风格不搭，反而失去"干净色块"的优点 |
| 写实水面倒影 | 用立方体贴图不值得，简化版波纹+泡沫更划算 |
| 外部模型/贴图资源 | 现在全程序化，引入资源会带来管线与体积成本 |

## 4. 性能红线

- 目标：**桌面浏览器 60fps**，draw call 控制在 **2000 以内**（现在约 1100-1300）
- 粒子一律用 InstancedMesh 或 Sprite 池
- 贴图分辨率上限 512×512（手绘噪点不需要更大），全部程序化生成
