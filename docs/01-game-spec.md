## 1. 一句话与核心体验

**一句话**：在一个低多边形卡通的乡村小岛里，玩家通过「潜行接近 → 观察 → 投喂 → 对话」建立好感度，最终和动物成为朋友、解锁它们的能力，一起探索整座小岛。

**这不是什么**：
- 不是「收集图鉴」——找到动物只是**开始**，不是结束
- 不是打怪/种田/经营——没有战斗、没有经济系统
- 不是限时挑战——没有倒计时、没有失败画面

**体验支柱（4 条）**

1. **治愈感**：无惩罚、无失败、无时间压力。动物被吓跑只是重新躲起来，探头冒个「？」看你
2. **信任感**：好感度不是数值刷条，是「它愿意为你停下脚步」的过程
3. **好奇感**：三层线索递进，越靠近线索越明确，鼓励你慢慢摸过去
4. **羁绊感**：动物有自己的性格、秘密、故事；动物之间互相介绍、互相牵线

**单次游玩**：20–30 分钟；5 分钟就能逛完一圈村子，但细节值得逛第二圈

参考图 p6《Explore! Piggy Island》给出的方向：

- **整体**：暖奶油天空 + 高饱和青绿海水 + 黄绿草地 + 暖沙色沙滩，明亮、夏日、干净

## 3. 世界观与场景

一座宁静的乡村小岛，玩家是一个来到村里的**新面孔**（小孩）。动物们一开始躲着你，因为你是陌生人。

### 3.1 场景元素清单（初稿，数量可调）

| 类别 | 初稿内容 | 初稿数量 | 备注 |
| --- | --- | --- | --- |
| 建筑 | 各色农家小院（红 / 黄 / 青屋顶）、柴堆、栅栏、烟囱 | 4 栋 | 每栋可住一只动物的「线索点」 |

| 自然 | 多色树 / 草丛 / 石头 / 野花 / 树桩 | 60 / 80 / 24 / 48 / 34 | **纯参考值，先做能跑通的量，后期加** |

## 4. 核心玩法循环（每天的重复循环）

```
① 发现线索 → ② 潜行接近 → ③ 观察确认 → ④ 投喂/对话 → ⑤ 好感度上升 → ⑥ 解锁新内容 → 回到 ①
```

### ① 发现线索（三层递进设计）

动物躲着时**不会直接暴露**，给三层线索，越走近线索越明确：

| 层级 | 距离 | 线索形式 |
| --- | --- | --- |
| 远 | 15m+ | 草丛轻微晃动、地上的脚印、掉落的羽毛 |
| 中 | 8–15m | 立体声叫声（能听声辨位）、咀嚼声、鼾声 |
| 近 | 5–8m | 草丛里露出尾巴尖/耳朵、眼睛反光、水面气泡涟漪 |

### ② 潜行接近（信任机制的核心）

- **正常走路/跑步靠近** → 动物**吓跑**（头顶冒红色 `!`），跑到最远的窝重新躲好
- **按 C 蹲下潜行靠近** → 动物**警觉**（头顶冒黄色 `?`），半撑起身盯着你、小心翼翼摇尾巴
- 警觉状态太突然站起 → 立刻吓跑；蹲太久（8 秒）→ 动物放松回窝
- **QUOKKA 式宽松原则**：吓跑**无任何惩罚**，走远一点它就重新出现（避免挫败感）

### ③ 观察确认

- 靠近到 **3.5m 内**，准星**变金黄** → 按 **E 观察**
- 弹出 **galgame 式观察卡**：动物的名字、性格描述、当前状态
- **首次观察 = 朋友入册**，左上角出现好感度 HUD

### ④ 投喂与对话

- 村里探索可以捡到食物：**肉骨头、小鱼干、鸟瓜子、龟水草** —— 每种动物喜欢不同食物
- **投喂** → 好感度 **+20** → 头顶飘爱心
- **选项式对话**（galgame 式）：每个好感度等级解锁新一轮对话树
- 喂错食物：不扣好感，只是动物「不太感兴趣」的反应（保持零惩罚）

### ⑤ 好感度与解锁

好感度 0–100，四个等级，每级解锁新内容：

| 等级 | 分数 | 解锁内容 |
| --- | --- | --- |
| 陌生 | 0 | 只能远远看到，靠近就跑 |
| 认识 | 20+ | 不再跑，接受投喂，基础对话 |
| 熟悉 | 60+ | 新对话树，告诉你**小秘密**（其他动物的线索！） |
| 挚友 | 100 | 专属剧情、**动物小队**（跟随 + 能力）、自由聊天（v2） |

### ⑥ 回到 ①

用「熟悉」阶段拿到的秘密线索，去找下一只动物 —— 这就是把循环串起来的钩子。

## 5. 五大玩法闭环（整个游戏的地基）

### 闭环 1：朋友簿（替代传统图鉴）

不是冷冰冰的「已收集 3/4」，而是一本**手绘感的朋友日记**：每只动物一页，记录它的**故事、性格、你俩的回忆、专属剧情线进度**。

> 收集的对象是「故事」而不是「图鉴条目」。

### 闭环 2：好感度 + 秘密网络

动物之间有关系网，**帮朋友 → 朋友帮你**：

```
帮猫找鱼 → 猫告诉你「狗怕打雷」 → 雷雨天靠近狗时用它不躲而是安慰
→ 狗告诉你「乌龟爱听歌」 → 带着狗去池塘放歌 → 乌龟出来……
```

**每只动物的「秘密」是解锁下一只动物的关键钥匙，动物之间会互相介绍。**

### 闭环 3：信任机制

即第 4 节的 ①②③④ —— 从「远远看到」到「能摸到」的全过程，是**游戏的手感核心**，也是 P2 阶段要最先验证的东西。

### 闭环 4：动物小队（好感度满 → 跟随 + 能力）

挚友后动物会**跟在你身后走**，并提供独特能力：

| 动物 | 能力 | 用途 |
| --- | --- | --- |
| 🐱 猫 | 发现高处 | 树上/屋顶的动物和物品会显示标记 |
| 🐶 狗 | 闻出踪迹 | 屏幕边缘出现气味指示，找到躲藏的动物 |
| 🐦 鸟 | 飞高标记 | 起飞盘旋，地图上标记兴趣点 |
| 🐢 乌龟 | 水下区域 | 驮你进池塘水下通道（新区域！） |

**组合技**：带狗 + 鸟出门 —— 狗闻到气味 → 鸟起飞确认位置 → 精准找到藏在深处的动物。

### 闭环 5：时间 / 天气系统

- **昼夜循环**：不同动物不同作息 —— 猫白天睡觉、鸟清晨叫、乌龟中午晒背、狗整天看家但傍晚最活跃
- **天气**：雨天动物躲进建筑（去屋檐下找它们）；雷雨天狗会发抖（用秘密网络的 knowledge 安慰它）
- **时间变化影响能遇到的动物和对话内容**

## 7. 设计原则（我们一路定下的规矩）

1. **漫步式无计时** —— 没有倒计时，没有失败画面
2. **每步验收** —— 每个版本你试玩确认后我才打 tag 推进下一步
3. **动物优先做深不做多** —— 4 只每只都有完整故事，不做 20 只浅尝辄止
4. **mimo 只在开发期用** —— 批量生成对话树/梗台词，你筛选后打包进游戏，v1 纯离线零 API 成本

**追加原则（我的建议，待你确认）**

5. **先闭环后内容** —— 先用 1 只动物跑通完整闭环，再复制到 4 只
6. **程序化优先** —— 场景（树/草/石/花）用代码生成，改一个数字就能调密度，不需要美术资源也能出效果
7. **数据与代码分离** —— 所有文案/数值进 JSON，你随时能改

## 8. 技术架构（初稿）

```
island-friends/
├─ index.html
├─ vite.config.js
├─ public/assets/            # 贴图、音效（后期）
└─ src/
   ├─ main.js                # 启动、主循环
   ├─ core/                  # 渲染器、相机、输入、时钟、资源加载
   ├─ world/                 # 地形、海滩、水面、道路、程序化散布（树/草/石/花）
   ├─ entities/              # 玩家、动物（状态机）、跟随队友
   ├─ systems/               # 潜行与信任、好感度、投喂、对话、朋友簿、存档
   ├─ ui/                    # HUD、观察卡、对话框、朋友簿、小地图
   └─ data/                  # animals.json / dialogues.json / items.json / world.json
```

| 项 | 选型 | 理由 |
| --- | --- | --- |
| 渲染 | Three.js（WebGL） | 轻量、低多边形风格友好 |
| 构建 | Vite | 秒级热更，改一下就能看到 |
| 材质 | 顶点色 + flatShading（v1）→ 后期叠加手绘贴图 | 先用代码出效果，不卡在美术资源上 |
| 天空 | 渐变天空球 + 雾 | 复刻 p6 的奶油天空氛围 |
| 动物 AI | 有限状态机（躲藏/警觉/好奇/信任/跟随） | 逻辑简单可调，方便你玩数值 |
| 存档 | localStorage | 纯离线，无需后端 |
| 音频 | Howler / WebAudio | 三层线索的「听声辨位」需要立体声 |
