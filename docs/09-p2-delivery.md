# P2 交付说明 · 大黄 + 信任闭环 MVP

> tag：`p2-trust-loop`
> 状态：**待你验收**
> 范围：只做**一只动物（大黄/狗）**，把「发现 → 潜行 → 观察 → 投喂 → 好感度」这条手感核心跑通。
> 明确不做：朋友簿、对话树、其他三只动物、动物小队跟随（留 P3 / P4）

---

## 1. 现在能玩到什么

| 玩法 | 表现 |
| --- | --- |
| **发现动物** | 大黄躲在 5 个窝之一（房后 / 村口草丛 / 池塘边 / 土地庙旁 / 航标塔下），每个窝周围自动长出一圈掩体草丛，趴在里面只露耳朵和尾巴尖 |
| **三层线索** | 远 15m+：地上出现**脚印**、飘落**羽毛**、草丛**晃动**；中 8-15m：隔一会儿传来**狗叫**（左右声道定位，能听声辨位）；近 5-8m：露出**尾巴尖**、**耳朵立起**、**眼睛反光** |
| **吓得跑** | 站着/跑着靠近 → 头顶冒红色 `!`，跑到**另一个更远的窝**重新躲好（无任何惩罚，走远它就回来） |
| **蹲行潜行** | 按 `C` 蹲下 → 移动速度降到 42%，姿势也蹲下来；这时靠近它只会**警觉**（头顶黄色 `?`），半撑起身子盯着你、小心翼翼摇尾巴，8 秒后放松 |
| **观察** | 靠近到 **3.5m** 内，屏幕**准星变金黄**并提示 `E 观察` → 按 `E` 弹出 **galgame 式观察卡**：名字 / 种类 / 性格 / 当前状态 / 一句它的心事 / 好感度 / 它爱吃什么 |
| **投喂** | 村里散落 10 处食物（肉骨头 / 小鱼干 / 鸟瓜子 / 龟水草），走到 1.7m 内自动捡起；按 `1-4` 选，按 `F` 投喂。**喂对**：狗开心哼叫 + 头顶冒爱心 + 好感 **+20**（12 秒冷却）；**喂错**：只是"不太感兴趣"，**不扣好感** |
| **好感度** | 0-100 四档：陌生 0 / 认识 20 / 熟悉 60 / 挚友 100。首次观察后左上角出现好感度面板（等级 + 进度条 + 当前该怎么做） |
| **认识之后** | 好感 ≥20：**站着走近也不跑了**，会看着你；好感 ≥60：**会主动凑过来一点**、尾巴摇得欢（跟随留到 P4） |
| **音效** | 全部程序化合成（WebAudio），**不需要任何音频文件**：狗叫 / 呜咽 / 开心哼叫，都带左右声道定位 |

## 2. 操作

| 键 | 作用 |
| --- | --- |
| `W A S D` | 移动 |
| `Shift` | 跑（会吓跑动物） |
| **`C`** | **蹲下潜行**（按住） |
| **`E`** | **观察 / 关闭观察卡** |
| **`F`** | **投喂** |
| **`1`-`4`** | 选择手里的食物 |
| `V` | 切换视角（跟随 / 全岛俯瞰 / 地面 / 资产总览） |
| `T` `[` `]` | 时间暂停 / 速度 |

地图调试参数：`?x= ?z=` 出生点 · `?aff=60` 直接给好感 · `?food=bone:3` 直接给食物 · `?dog=alert|flee|curious` 强制状态 · `?dist=5` 相机拉近

## 5. 数值都在哪（你想调手感就改这个）

全部在 **`src/data/animals.json`**：

```
trust.observeRange    3.5   观察距离
trust.clueFar/Mid/Near 15/8/5 三层线索距离
trust.fleeRadiusRun    12.0  跑着靠近多少米会吓跑它
trust.fleeRadiusWalk    6.8  站着靠近
trust.fleeRadiusCrouch  2.4  蹲着靠近（特意设得比观察距离小，否则永远没法第一次观察它）
trust.alertRadius*     18/11/7 多近会被它发现（警觉）
trust.calmAfterSec      8.0  警觉多久后放松
trust.fleeDistance     24.0  逃跑时最多跑多远换窝
affection.feedGain     20    投喂加多少好感
affection.feedCooldownSec 12 投喂冷却
speed.flee/walk        6.2 / 1.5 它的移动速度
```
食物产地、数量在同一个文件的 `foods.spawns`。

## 6. 请你验收

- [ ] 打开游戏往**村口草丛**走（出生点往东北），会不会先看到**脚印/羽毛/草动**，再听到**狗叫**（戴耳机能听出左右）
- [ ] **站着**靠近它 → 是不是被吓跑（头顶 `!`），跑到另一个窝；走过去它还在不在
- [ ] **按住 `C` 蹲下**再靠近 → 是不是只警觉（`?`）、不跑；8 秒后自动放松
- [ ] 蹲到 3.5m 内 → 准星变金 → 按 `E` 看**观察卡**内容对不对、好感度面板有没有出现
- [ ] 捡一根**肉骨头**（先逛逛）→ 按 `F` 投喂 → 爱心、+20、升到"认识"
- [ ] 升到认识后**站着**再走近试试，它是不是不跑了
- [ ] 手感数值（吓跑的距离、蹲行速度、警觉时长）要不要调 —— 直接说"太容易吓跑/太宽容"，我改 `animals.json`
